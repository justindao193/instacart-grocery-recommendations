# Original files

These six CSVs are kept as downloaded. The original publisher is Instacart; the working copies came from the Zenodo archive linked in the source manifest.

Run `03_Code/download_data.py` to retrieve and check them again. A file is accepted only when it matches the archive's published MD5 checksum. SHA-256 fingerprints are also recorded for later change checks.

The original release, data dictionary, usage terms and archive details are linked in `01_Project/03_Data_And_Methods.md`. Keep the raw data local rather than uploading it with the portfolio code.
