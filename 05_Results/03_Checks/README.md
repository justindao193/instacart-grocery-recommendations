# Check reports

source_manifest.json records download provenance and original file fingerprints. prepared_manifest.json records prepared file fingerprints. preparation_report.json and verification_report.json record structural and preparation checks.

The remaining JSON reports contain validation results and diagnostics from the runnable scripts in 03_Code. They aren't final evaluation or measured shopping benefits. Customer-level generated records stay in 02_Data/03_Model_Outputs and are excluded from Git.

Historical design previews were moved to 99_Archive/02_Design_And_Preparation_History.
